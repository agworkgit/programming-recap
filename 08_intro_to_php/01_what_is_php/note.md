# What is PHP?

## Definition

- Originally, it standed for Personal Home Page
- Now, it stands for Hypertext Pre Processor
- As a language it allows you to **dynamically write web pages**, this is not the same as writing dynamic web pages with JavaScript.

## Dynamically Written Pages VS Dynamic Pages

- **Dynamically writing** a web page means based on certain factors PHP will literally write a web page for you, it will add in the HTML, CSS, JavaScript.
- **Dynamic web pages** are created in JavaScript, think of all the intractive aspects of a web page, animations, hovers, etc..., all of that is created in JavaScript.
- PHP decides what shows up on the page based on certain variables.
- PHP is a scripting language. (interpreted on the server)

## Server-side Scripting Language

- All the code itself is executed on the server not on a client, and then sent to a client-side browser.
- JavaScript is interpreted on the client-side, the browser gets a JS file and executes it on the client-side.
- The value in this is that it makes the code more secure, the browser can't see database transactions and information retireval. The browser only sees the finished page.
- Think of it as the **secretary** of the Internet.
- You won't be doing super interactive pages, such as games, high interactivity stuff with PHP.
- PHP is essentially used for that feature of dynamically writing web pages on the server-side and connecting to databases.
- Much of the chunk of work done in PHP is in administrative internet functions (reports, newsletter blasts, etc...).
