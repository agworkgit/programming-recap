# Why Do Coders Hate PHP?

## Negative Opinions

- A lot of coders out there will tell you that is utterly stupid to learn PHP and that you should go and learn another language.
- One of the main problems with PHP is that more-or-less a secretary could use it, it was designed to be incredibly easy to use.
- Again, PHP does all of that basic kind of administrative tasks that lower level professionals might need to do (collecting emails, doing email blasts, doing reports, etc...)
- It was designed to be written easily but does not necessarily obide common practice code standards.
- One of the issues of PHP is that it doesn't prevent you at all from writing some really ugly code that works. But if someone else tries to review your code afterworks they will have a horrific experience.
- Others complain about security issues with PHP, it is very easy to write insecure code in PHP, and on top of that diffcult to audit and understand what's going on.
- Think of things such as asset tracking, in larger organisations, fixed asset tracking is a big deal, making sure you know all the computers that you have in your inventory, knowing when they were purchased, the price they were purchased for, knowing the depreciation over time, and so you might have a company that was growing very quickly that did not have a good way of tracking their fixed assets, so you bring a little helpdesk technician and they figure it out and do a system in PHP, and they slap together some ugly PHP code that runs well functionally, and this idea will then spread to other departments within the organisation like wildfire.
- So the issue is that that person might go away and leave 1000s of lines of mess behind them that someone who might come in later to implement new functionality will have to fix.
- Therefore this is not really a PHP problem but a code review, audit, coding standards problem that said organisation did not put in place.

## The Functional Argument

- Many people will say, if you're gonna learn a functional programming language, why not learn Python? Which is a valid argument, depending on what you end up doing.
- But, the flip side is that there is a tremendous amount of PHP code out there that people need to optimise.
- So the big answer here is that PHP has a lot of market share, documentation and legacy code at this point if you end up getting a job where you have to maintain PHP code.
- Learn it even if you end up using something else for the sake of exposure.
