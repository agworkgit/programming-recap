# Why Learn PHP?

## A Question That Keeps Coming Up

- Why should you learn PHP? When there's JavaScript, JAVA, Ruby, etc... that many people say are far superior.
- You should learn it because it is used in a tremendous amount of web apps that you're going to be using on a day-to-day basis or run into.
- If you look at apps like Wordpress, Drupal, Joomla, may of the open source web apps that you will download and install into your server will use PHP.
- It's a language that's been around for a long time, a very popular one as well in the web domain, so a lot of open source applications you will download and deploy will be using PHP.

## Is It The Best?

- Is PHP the best for running the mentioned applications? Could those apps run better if they were coded in one of those others programming languages, maybe..., but the fact of the matter is that with open source projects when they put in 10 years or more into creating a product they won't simply go back and re-write the project just to make it a little faster.
- Essentially, there are many apps and projects at this point running PHP.
- So even if you won't end up working with PHP as a career, you should still know what it does and how to poke around a PHP program to figure out what's going on.

## It Is A Ridiculously Easy To Learn Language

- It does not have the same amount of rules as other languages.
- So you can go in and create something functional relatively easy.
- Within a week you should be able to create applications that can do what you need.
- PHP pulls and dumps data from a database very easily, which is the majority of work people do on the Internet.
- Remember, we are not married to the programming languages we use.
- So if you want to learn PHP, you should also know JS, HTML and CSS, because PHP works in conjunction with those to create dynamically written web pages.
- So by understanding the limitations of PHP you will quickly be able to work out which language you need to use to code a specific type of applications which a specific set of features and a specific runtime environment (browser, desktop, server, etc..).
- These days you should be **solid in at least five different languages** if you want to build up a career as a programmer.
